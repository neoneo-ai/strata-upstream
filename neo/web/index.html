编码 agent 一键接入

      

      
每一行就一条命令：复制到终端跑，Neo 把服务地址、token、模型与上下文
         都算好，直接把 agent 带上下拉起来（加 --no-launch 只打印命令）。Codex / OpenCode /
         OpenClaw 认配置文件，点「写进配置」会先把它现有的配置备份成 .neo-bak 再合并
         （解析不了的文件 Neo 不动）。连远程那台 Strata：设 NEO_SERVER_URL 与 NEO_API_KEY
         两个环境变量再跑同一条命令。

Neo 只按 neo/engine_ref.json 钉住的那一个
        tag 取源码（git clone --depth 1；没有 git 就下载 zip，SHA-256 与 pin 一致才解压），
        放进 strata/。venv、依赖、引擎二进制、模型全交给上游的 setup.py，
        Neo 一个都不自己装。这一页写过的东西都在 strata/ 与 neo/state/ 里，
        上游文件一个不改；目录里有人改过（dirty）时 Neo 拒绝动它。
